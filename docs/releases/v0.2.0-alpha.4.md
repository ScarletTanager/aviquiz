# AviQuiz v0.2.0-alpha.4

Release date: November 28, 2026 (initial packaging/tagging). Includes all alpha.3
capabilities. Initially packaged for staging; production promotion requires owner
approval of that tested candidate and preserves this date and immutable tag.

## User-visible changes

- Geography quizzes open in a dedicated quiz view without briefly showing Home or
  the legacy Practice setup. Loading failures offer retry/return controls.
- Take a quiz remains the active navigation destination for geography sessions.
- Desktop headers accommodate Spanish and invitation controls without shrinking
  fonts; smaller screens retain safe wrapping.

## Technical changes

- `/explore` hands off to `/play?...`. The existing engine is shared, while `/quiz`
  remains legacy Practice. Old `/quiz?geo=...` links receive launch HTML and are
  canonicalized client-side without losing scope/date/family/count parameters.
- The build generates bilingual initial launch markup from the shared canonical
  template. Home/setup are hidden in server HTML before JavaScript executes.
- Geography initialization starts before optional audio/annotation requests finish.
  Those later completions cannot reset a running geography session to setup.
- Async failures remain in the launch view; retry clears stale errors. Navigation
  tokens prevent delayed completions from hijacking another destination.
- Shared desktop CSS tightens nav gaps and suppresses the decorative tagline where
  needed; mobile wrapping remains available and no menu redesign is introduced.
- No application database migrations or serving package/object revisions changed.
  Existing NC/Colombia coverage, media credits and historical statistics behavior
  are preserved; the original Colombia practice itinerary remains available.

## Validation

Local application/audio, geography, launch HTML, navigation, release/tag/date,
localization and HTTP regressions passed. Headless browser checks in both languages
held data, geography, audio and annotation requests: only loading/session views
appeared, sessions started independently of optional requests, failures/retry worked,
and canceled launches could not replace Practice. Header checks covered desktop
breakpoints, invitation controls and mobile overflow. Secret scans passed.

Engineering details remain here and in GitHub notes; the public website describes
only user-visible changes. See RUNBOOK.md for launch diagnosis and DEPLOYMENT.md
for the immutable-tag/staging-approval promotion procedure.
