# AviQuiz v0.2.0-alpha.2

Release date: November 28, 2026 (packaging/tagging). This release includes all
capabilities introduced in the alpha.1 staging candidate, plus consistent header
navigation. Alpha.1 was not separately deployed to production.

## User-visible changes

- English and Colombian Spanish interfaces with a persistent language selector.
- Colombia-wide seasonal quizzes at country, department and supported-site levels.
- Photo selection favors the quarters covered by the selected seasonal window.
- Optional account statistics, historical browser-statistics import, consent and
  latest-result comparisons; guest quizzes remain available.
- Consistent navigation to quiz creation, practice, trips and statistics.

## Implementation and operations

- i18next message bundles replace embedded interface text. Canonical page templates
  generate both language variants; key, interpolation and translation parity are checked.
- Common portable processing packages support CLI geography extraction, conversion,
  validation and photo assembly. The collector queue shares already collected species
  across geographies and retains seasonal photo dates and credits.
- Frozen NC and Colombia packages share a single photo-metadata snapshot. They cover
  2,171 unique species, 34 first-level geographies and 8,872 sites. All species have
  photo references; 54 species-quarter slots remain below the two-photo target.
- The quiz reader verifies immutable fact ranges and supports arbitrary-precision
  year masks, cross-year seasons and leap days. The original Colombia itinerary remains.
- Migration `0004_user_statistics` adds preferences and aggregate summaries, with
  cumulative totals and latest results rather than a per-question grading archive.
- Shared navigation templates preserve account-based invitation visibility.
- Runtime adapters continue supporting D1, SQLite and PostgreSQL. Staging and
  production packaging differ by host while preserving tested code/data revisions.

## Validation

Local application, authorization, i18n, seasonal-data and SQLite/PostgreSQL checks
passed. Eighteen production seasonal-query comparisons matched the frozen staging
baseline. CodeQL, secret scanning, dependency checks and PostgreSQL 17/18 CI passed.
The original alpha.2 CI geography regression failed because private local objects
were unavailable on GitHub; it passed locally, and subsequent development adds
self-contained fixtures to remove that dependency.

The external-catalog/Spaces refactor is subsequent development, not part of the
alpha.2 binary. See the development branch and PR #7 for that separate change.
