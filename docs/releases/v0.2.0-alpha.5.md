# AviQuiz v0.2.0-alpha.5

Release date: November 28, 2026 (initial packaging/tagging). Includes alpha.4.
Initially packaged for staging; production promotion requires owner approval of
this tested source and retains the release date and immutable tag.

## User-visible changes

- Country/subregion menus activate reliably on the first native click, including
  Colombia's departments in Chrome.
- Keyboard activation and retrying the same row after a temporary failure work
  without clicking an unrelated location first.

## Diagnosis and implementation

Three fresh Chromium sessions reproduced the issue with actual option clicks:
Colombia became selected without an input/change event, and the client sent no
Colombia directory request. A separate backend request returned all 33 departments
in about 0.24 seconds during diagnosis. This was not an indefinitely pending
metadata request in those reproductions.

The native listbox starts with selectedIndex=-1. Chromium can select its first
enabled option on focus/click without emitting change. The old change-only handler
missed that activation; programmatic select_option tests always emitted the event
and concealed it. The fix accepts change, click and Enter/Space activation and
deduplicates the same current selection. Returning from a child to its ancestor
still loads the ancestor. Failed selections stay retryable with a same-row click.
Unsupported rows remain disabled, and stale-request protection is preserved.

No serving data, object revisions, database migrations, statistics, permissions,
credentials or hosting policy changes are required.

## Validation

- The patched frontend loaded all 33 departments on the first click in three fresh
  browser sessions against read-only production metadata, with one directory
  request per selection. The patched module was local to the test browser, not
  deployed to production during diagnosis.
- The optional native Chromium fixture test covers mouse, keyboard and retry in
  English and Spanish entirely offline, without credentials/screenshots/recording.
- The standard CI geography test models click-only selection, duplicate events,
  keyboard, failure/retry, ancestor navigation and stale completions.
- Existing geography, launch, localization and application checks remain applicable.

See RUNBOOK.md's native-listbox diagnosis and scripts/test-geography-native.py.
The public website notes contain only user-relevant behavior, not these internals.
