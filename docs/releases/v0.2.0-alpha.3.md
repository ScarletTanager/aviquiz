# AviQuiz v0.2.0-alpha.3

Release date: November 28, 2026 (initial packaging/tagging). Includes alpha.2 and
its inherited alpha.1 capabilities. This source is initially packaged for staging;
production promotion requires the owner's staging approval and preserves this date.

## User-visible changes

- Geography quiz improvements preparing for broader coverage while preserving NC
  and Colombia seasonal quizzes, filters, photo dates and credits.
- Newest-version-first release notes with explicit alpha.1 inclusion in alpha.2.
- Consistent release dates across environments and public notes focused on users.

## Technical changes

- `aviquiz-serving-release-v1` replaces embedded place/species/photo catalogs with a
  small committed manifest and hash-verified, compressed navigation/species shards.
  The processing/collector contract remains `aviquiz-seasonal-package-v1`.
- Per-package bird indexes preserve original fact numbering and photo order.
  Identical species records are shared; different metadata variants stay distinct.
- One reader supports R2 in staging, private DigitalOcean Spaces and local files.
  A bounded LRU, coalesced reads, bounded concurrency, schema/digest/size checks and
  guarded decompression limit resource use. The catalog API reports the serving
  schema/revision so deployment verification can distinguish code generations that
  reference the same underlying package revisions.
- CLI preparation generates all immutable objects. Verification enumerates all
  metadata and facts. The Spaces uploader preflights local files, uses private
  objects and reads them back; packaging can omit mirrors only with a complete
  receipt. Runtime/private-DNS settings fail closed rather than use public fallback.
- Existing 2,171 species, 34 first-level geographies and 8,872 sites are unchanged.
  Metadata adds about 2.44 MiB compressed; the committed manifest is about 74 KiB.
  The original Colombia practice itinerary remains available.
- `releaseDate` replaces the deployment-date field. An annotated-tag/source/date
  guard freezes dates across staging and production. Technical notes live in GitHub
  and this directory, while the website lists user-relevant changes only.
- CI has synthetic serving fixtures; private EBD files are no longer required for
  geography/launcher regression checks. Application database migrations are unchanged.

## Verification and publication

Local processing CLI, shared queue, portable-package validation, storage/corruption/
concurrency, navigation, localization, release/tag/date, HTTP, authorization/statistics
and SQLite/PostgreSQL checks passed. Eighteen frozen seasonal comparisons matched
exact species order, photo URLs, photographers and dates; twelve independent daily
SQL comparisons passed. All 525 common objects and four legacy objects were uploaded
and verified through private Spaces, and eighteen parity cases passed via that adapter.
GitHub security and CodeQL checks passed for the implementation and release-policy
changes before this packaging update.

See docs/serving-format.md and docs/ebd-geography-cli.md. Retain previous object hashes
for rollback. Initial R2 bootstrap requires loading the new metadata after the
matching import endpoint is published; a published Worker alone does not mean data
is ready. Serving readiness is recorded separately and verified before handoff.
