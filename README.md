# Colombia Field Quiz

Static, browser-local quiz built from checklist_dec2026.xlsx and the October 7, 2026 eBird export. The original eBird observation history stays in the parent workspace; hosted data includes the trip checklist, site flags, lifer booleans, and public Macaulay photo metadata only. Quiz learning history stays in each visitor's browser.

Counts: 849 trip species, 283 potential worldwide lifers, 519 potential Colombia lifers (including worldwide lifers). Thirteen named site columns are supported; the empty OS column has no targets or site legend and is not offered as a site. The all-trip choice includes species with no site X. Thirteen checklist scientific-name errors were reconciled against Cornell taxonomy by unambiguous common names. Original source files are unchanged.

Photo metadata: four ranked Macaulay Library photo records per species, 3,396 total. Asset IDs, species labels, and contributor credits were read from Macaulay catalog pages. All 849 species have records, with no species-label mismatches. Images are loaded from Cornell's observed image endpoint; no photos are bundled or substituted from another provider.

Verification: node test.mjs covers all 39 site/filter combinations, the worldwide/Colombia lifer relationship, punctuation and typo matching, exact other-species rejection, distinct-species question sets, and photo provenance. Browser checks cover setup, site/filter selection, question count, image failure handling, unscored continuation, and results. Cornell's image CDN initially returned HTTP 403, then recovered. Final checks on the published site confirmed the hero and quiz photographs loaded, a two-question La Florida/worldwide-lifer session completed with 2/2 correct, a minor spelling error was accepted, results and photo credits displayed, and settings remained usable. The UI retries alternate records and allows an unavailable question to continue without scoring.

The family selector combines with site and lifer filters. It uses the checklist's family assignments, with parenthetical species counts removed from labels. All families mode uses distinct species. A specific family samples distinct Macaulay photo IDs, so the same species can appear with different photos; quiz length is capped to the available photo pool. Chicaque + Furnariidae has 26 species and 104 photo records. Empty intersections disable Start and explain how to change filters.

Family-filter verification: all family/site/lifer intersections pass automated checks. A browser session completed 30 Chicaque/Furnariidae questions with 30 unique images across 20 species. Additional browser checks confirmed worldwide-lifer narrowing (8 species / 32 photos), empty intersections disabling Start, the 104-photo cap, and returning to All families restoring distinct-species mode.

For development, serve dist/ using a static HTTP server. Data preparation uses the bundled Python runtime with openpyxl for read-only spreadsheet extraction. prepare_data.py rebuilds checklist data and resets photos; finalize_photos.py attaches saved catalog metadata again. The default quiz is 20 questions. Name matching accepts common, accepted common, and scientific names; removes punctuation and spacing; accepts at most one or two edit errors depending on length; and requires a unique closest match.

## Persistent mistake review

Learning history starts with this update and is stored per species code in localStorage under `colombia-field-quiz:progress:v1`. Each species retains its last 20 scored answers (or all answers if fewer). A strict miss rate greater than 25% qualifies it for recent review. A single miss qualifies until enough successful answers lower its rate; no arbitrary minimum sample is imposed. Wrong and revealed answers are misses. Unavailable photos do not enter history. Answers save immediately, including when a session is later abandoned. Regular and review outcomes both update the same history. Storage failures fall back to this-visit memory with a visible status; browsers/devices and separate visitor profiles do not share results.

Recent review combines the site and family selectors, ignores lifer filters, and asks once per eligible species. The end-of-quiz action uses deduplicated mistakes from that particular session regardless of overall miss rate. It retains site/family scope and chooses different photos from the just-completed quiz when alternatives exist. Repeating that specific review retains its species cohort; repeating a recent review refreshes current threshold eligibility. Another quiz preserves the active settings. Start over resets the form to regular/all-sites/all-families/no-lifer-filter/20 questions without erasing history.

Verification: automated checks cover serialization/reload, strict 25% boundary, the rolling window, all site/family review intersections, session-only deduplication, unavailable exclusion, and fresh-photo selection. Browser tests completed a regular quiz with one correct, one revealed, and one wrong answer; a two-species quiz-only review with fresh images; repeating the same review settings; default reset; persistence after page reload; empty filter intersections; hidden lifer filters in review; and graduation from review after correct answers brought both species to exactly 25% misses.

## Homepage accuracy summaries

The left side of Choose your patch shows site accuracy across all families and family accuracy across all sites. Percentages divide correct answers by answered photos, summing each species' retained last-20-attempt window. These are weighted answer totals, not averages of species percentages. Site groups use the checklist's X flags, including answers from other quiz scopes; a shared species contributes once to each relevant site. Unattempted species add no denominator and groups without answers show a dash. The summaries are independent of the current quiz filters and update on scored answers, return to setup, and cross-tab progress events. Stored progress is unchanged.

Families default to checklist taxonomic order, show the first ten, and expand to all 72. Independent site/family controls sort by checklist order (itinerary for sites, taxonomy for families), alphabetic name, or correct ID rate, ascending or descending. Groups without history stay last when sorting by rate in either direction. Formula text and expandable calculation help explain the history window, regular/review inclusion, revealed answers, unavailable photos, overlapping sites, and browser-local storage.

Verification covers weighted aggregation, site overlap, empty versus 0% groups, species without site flags, both directions of every sorting option, and immutable history. Browser checks verified 13 sites, ten collapsed families, 72 expanded families, all 12 sort/direction combinations, calculation help, unchanged summaries when quiz filters change, a new correct Oilbird answer updating family and site rates, and persistence after reload.
